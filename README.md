# FizzBuzz Calculator
 
## Overview
This Python program analyzes numbers from 1 to 100 and categorizes them according to the classic FizzBuzz rules:
 
- **Fizz**: Numbers divisible by 3
- **Buzz**: Numbers divisible by 5
- **FizzBuzz**: Numbers divisible by both 3 and 5
 
Instead of printing each number, the program calculates the cumulative sum of the numbers in each category and displays the results.
 
## Features
- Iterates through numbers 1 to 100 using a while loop
- Uses conditional statements to classify numbers
- Calculates separate totals for:
- Fizz numbers
- Buzz numbers
- FizzBuzz numbers
- Displays the final sums in a user-friendly format
 
## Technologies Used
- Python
- Conditional Logic
- Loops
- Arithmetic Operations
- Modulo Operator (%)
 
## Code Functionality
The program checks each number from 1 to 100:
 
1. If the number is divisible by both 3 and 5, it is added to the FizzBuzz total.
2. If the number is divisible only by 3, it is added to the Fizz total.
3. If the number is divisible only by 5, it is added to the Buzz total.
4. The program continues until all numbers have been evaluated.
 
## Sample Output
 
The sum of all FIZZ numbers is: 1203
 
The sum of all BUZZ numbers is: 735
 
The sum of all FIZZBUZZ numbers is: 315
